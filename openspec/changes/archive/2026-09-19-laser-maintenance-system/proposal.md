# Proposal: 激光设备售后维修维保系统

## Why

激光设备（切割机、焊接机、雕刻机等）价值高、专业性强，维修依赖售后体系。目前缺乏统一的数字化管理平台：客户报修流程不规范，工程师派单靠人工调度，提成计算不透明，配件库存信息不透明。亟需构建一套连接客户、工程师、客服三方 的数字化维保系统，实现报修-派单-维修-结算-评价的全链路管理。

## What Changes

- **客户侧 App**：扫码/序列号识别设备、快速故障选项、在线预付定金、订单跟踪、评价退款
- **工程师侧 App**：实时抢单/接单、GPS 位置上报、现场拍照签字、完工提交、收益统计
- **客服后台**：工单初步分类、远程诊断解决、历史对话查看、客户/设备管理
- **派单引擎**：抢单池 + 指定工程师推送，工程师位置实时计算距离
- **提成系统**：月度阶梯式提成（1-10 单 20%/11-30 单 25%/31+ 单 30%）
- **配件库存**：仓库库存实时查询、预计补货时间、缺货提醒
- **数据脱敏**：序列号、姓名、电话、地址对工程师/客户分级脱敏展示

## Capabilities

### New Capabilities

- `customer-app`：客户移动端应用，支持设备报修、订单管理、在线支付、评价退款
- `engineer-app`：工程师移动端应用，支持抢单接单、完工提交、收益查看、仓库查询
- `cs-backend`：客服后台管理系统，支持工单分类、远程诊断、客户设备管理
- `work-order`：`工单全生命周期管理`，覆盖创建、派单、施工、完工、评价、取消、退款各状态
- `commission`：`阶梯提成计算规则`，按月接单量动态确定提成比例并结算工程师收益
- `parts-inventory`：`配件库存管理`，支持多仓库、库存状态、预计补货时间查询
- `dispatch-engine`：`派单引擎`，支持抢单池、指定工程师推送、GPS 距离排序
- `payment`：`定金预付与退款`，30% 定金、多退少补、24h 全额退款原路退回
- `device-archive`：`设备档案管理`，设备绑定、序列号脱敏、保修状态、维修历史

## Impact

- 新建客户 App、工程师 App、客服后台三套前端应用
- 新建 NestJS 后端服务，提供 RESTful API + WebSocket 实时推送
- 新建 PostgreSQL 数据库，17 张核心表
- 集成微信支付/支付宝、极光推送、高德地图
- 涉及敏感客户信息，需实施数据脱敏策略
