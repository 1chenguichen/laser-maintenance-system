# Tasks: 激光设备售后维修维保系统

## 工作分解

基于 design.md 的五阶段部署计划，将项目拆分为可执行的任务。

---

## 阶段一：基础框架搭建

### 1.1 项目初始化

- [ ] 初始化 NestJS 后端项目，配置 TypeScript、ESLint、Prettier
- [ ] 初始化 React Native 客户 App 项目
- [ ] 初始化 React Native 工程师 App 项目
- [ ] 初始化 React 客服后台项目（Ant Design Pro）
- [ ] 配置 Git 仓库和 CI/CD 基础（GitHub Actions）

### 1.2 数据库设计

- [ ] 创建 PostgreSQL 数据库，配置连接池
- [ ] 设计并创建 17 张核心表（DDL 脚本）
- [ ] 配置 TypeORM/Prisma ORM，建立实体映射
- [ ] 编写数据库索引策略文档
- [ ] 初始化 Redis 连接，配置 Session 存储

### 1.3 基础认证模块

- [ ] 实现 JWT Token 签发和验证
- [ ] 实现短信验证码登录（需选定短信供应商）
- [ ] 实现角色鉴权中间件（customer/engineer/cs_operator）
- [ ] 实现 Token 刷新和登出机制
- [ ] 编写 API 统一错误处理和错误码规范
