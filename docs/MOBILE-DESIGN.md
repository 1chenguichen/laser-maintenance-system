# 移动端样板与设计规则

## 第三轮：统一订单与报修表单

订单页现为企业售后与平台服务的统一列表，支持状态筛选、来源筛选和设备/SN/订单号搜索。个人中心订单计数同步包含两类记录。

设备报修页已从旧的全量卡片选择器重构为当前设备摘要、故障信息、上门信息、合同可选项和提交区域；设备入口锁定已选设备，切换设备为显式操作。页面使用与首页一致的字体、卡片、图标、设备缩略图和控件，地址与草稿留在当前用户会话中；故障照片显示本地预览。

两端登录与注册页也已接入 `auth-reference.css`，保持客户端蓝色、工程师端绿色。认证流程未改动。

测试 `mobile-workspaces.mjs` 新增实际设备报修、后台 SN 校验、照片权限、重复提交、统一订单筛选及企业合同权益验证。历史章节记录的是此前阶段，不表示这些页面仍未统一。

本轮完成六个样板：客户端 `home.html`、`services.html`、`platform-order.html`；工程师端 `workbench.html`、`opportunities.html`、`platform-order.html`。订单列表、培训和申请页继承共用控件；旧设备详情、企业任务、个人中心等其余页面尚未全部重构。

## 第二轮：现有业务页面延续

23 个旧业务页已接入角色对应的 `mobile-continuity.css` 和 `mobile-continuity.js`：客户端 12 页（设备、地址、企业工单、个人中心、合同发票、延保、报修、工单进度、账单确认、支付结果、退款、客服），工程师端 11 页（企业任务、企业派单、历史记录、移动仓、个人中心、收益、任务详情、报价、签字、AI 助手、报告草稿）。这些页面统一标题栏、460px 容器、字体层级、卡片、控件、菜单、底栏、弹窗和焦点样式；保留原业务脚本与数据权限。

个人中心使用本地图标，平台入口改为统一列表，并放在退出登录之前；聊天页使用可滚动消息区与独立输入区；设备页移除重复引导；旧弹窗支持键盘 Tab 限制和 Esc 关闭。底部导航补全旧业务页面的所属栏目。

客户仍采用蓝色与较大圆角，工程师采用绿色、较紧凑布局及较小圆角。登录和注册页尚未纳入此次业务页面扩展；本轮也没有重写这些页面的业务流程。

开启 `MOBILE_DESIGN_AUDIT=1` 后运行 `node backend/test/mobile-workspaces.mjs`，检查 23 页的 320/430/1280 宽度、地址弹窗和移动仓三种表单。`MOBILE_SCREENSHOTS=1` 才保存本轮页面检查截图，默认不额外保存。

## 客户端：设备服务

蓝色 `#1669df`，浅灰蓝底，中性深色正文。留白较多，主要卡片圆角 20px，首页介绍区 24px。首页按服务入口、待确认事项、设备、进行中服务排序。保留企业保障内报修与市场服务两条业务路径；原企业工单的付款、评价待办仍从真实接口读取，不伪造进度。

服务列表按城市与类别筛选；需求表单在可关闭的对话框中填写。工单详情按进度、设备和需求、工程师、报价、服务记录排列，企业责任信息折叠展示。操作文案面向客户，不向客户显示“提交报价”“确认接单”等工程师操作。

## 工程师端：现场工作

绿色 `#147552`，灰绿底，中性正文。卡片圆角 12px，控件圆角 9px；任务以左边状态线和文字区分。工作台显示当前身份、待处理/服务中/待客户确认统计、常用工具、待履约任务。企业任务与移动仓独立入口保留。统计来自已分配的平台任务，不将企业任务混入同一计数。

接单大厅只展示后端允许领取的任务摘要。客户联系入口与地址在领取后展示。任务详情优先呈现客户联系人和服务现场信息，底部固定当前操作。

## 共用交互

- 本地字体与本地图标，无新增外部 CDN。主文本、次要文本、辅助文本分级；正文避免全部使用主题色。
- 容器最大 460px 居中；320px 窄屏可用；分类标签在局部横向滚动，页面本身不横向溢出。
- 表单字体 16px，主要按钮触控高度至少 44px；键盘焦点可见；图标按钮提供中文可访问名称。
- 详情底部操作栏与底部导航分别定位，正文预留底部空间。设备责任关系和服务动态可向下浏览。
- 表单、确认操作采用同一套原生 `dialog` 样式，支持返回和 Esc 关闭。弹窗错误在弹窗内部显示，保留已填写的内容。
- 轻微进入动画 200ms；尊重系统“减少动态效果”设置。
- 加载失败不当作“没有数据”；部分接口失败保留已读取的数据并提示重试。

样式入口为两端的 `mobile-reference.css`，业务渲染入口为 `market-ui.js`。两端文件保持同步，以 `data-role` 实现布局与风格差异；不在单页随意叠加新的颜色或按钮样式。

验收：`node backend/test/service-market.mjs` 覆盖六个页面的 320/414/1280 宽度、真实需求提交、接单、确认弹窗、带小数的报价以及后端权限闭环。`node backend/test/mobile-workspaces.mjs` 回归原设备、企业工单、服务商归属和工程师工作空间。截图默认不保存；需要临时视觉检查时设置 `MARKET_SCREENSHOTS=1`，检查后清理。
