# 客户与设备 Excel 导入

入口：企业管理后台 → 客户管理 → 导入 Excel。

1. 点击「下载模板（含示例）」。
2. 填写页直接展示表头和黄色示例行：第1行表头、第2行示例，从第3行填写真实资料。示例行有「行类型=示例（不导入）」标记，会自动跳过。真实行的行类型填「数据」或留空。
3. 客户姓名、手机号码必填。设备页可选；填写设备时，设备序列号、设备型号、设备类型必填，通过客户编号或客户手机号关联本次客户名单。
4. 如填写地址，省份、城市、区县和详细地址须齐全。日期填写 YYYY-MM-DD，手机号和序列号建议使用文本格式。
5. 上传 .xlsx 文件并点击「检查文件」。有错误时显示工作表、行号和原因，可下载 CSV 错误清单。修改原文件并重新上传。
6. 检查通过后核对当前企业和处理预览，再点击「确认导入」。

规则：
- 单次最多500位客户、1000台设备，文件不超过5MB；旧 .xls 文件请在 Excel/WPS 中另存为 .xlsx。
- 同一企业内，手机号与姓名均一致时跳过已有客户，不覆盖客户原资料；仍可添加新的设备、地址。新增设备的补充资料会追加到原客户档案。
- 相同手机号但姓名不一致、设备序列号冲突、重复表头、公式或无效日期会阻止导入，不会静默覆盖。
- 先预览后确认，预览不会写入。预览有效15分钟，文件、账号、企业或现有资料变化需重新检查。
- 客户、设备、地址的业务写入在同一数据库事务中执行。若身份关联同步失败，界面会提示资料已保存及重试方式；重新上传同一文件不会重复新增。
- 设备品牌、维保方案、登记工程师等作为补充资料保存；不会据此生成工程师账号、合同、付款或发票。
- 兼容此前生成的信息表（前10行内识别表头）。其他自有表格可按模板调整工作表名及列标题后上传。

接口（仅当前企业管理账号）：
- GET /admin/customer-import/template
- POST /admin/customer-import/preview，multipart/form-data，file
- POST /admin/customer-import/commit，multipart/form-data，file + token

验证：`node backend/test/customer-import.mjs`

测试使用临时企业及独立数据库，结束后清理。覆盖真实导入、重复导入、给已有客户追加设备、原资料保留、错误行定位、日期与公式校验、跨租户及权限拦截、文件变更、并发变更、事务回滚、客户登录关联和真实浏览器上传/下载流程。需要8180/3100服务和9324测试浏览器运行。


## 设备独立导入

设备管理 → 导入 Excel，下载设备专用模板（打开后直接是设备填写页）。通过客户手机号或已登记客户编号关联当前企业已有客户，二者同时填写时须对应同一人。不创建客户账号；客户不存在时请先到客户管理新增或导入。

接口：GET /admin/device-import/template；POST /admin/device-import/preview；POST /admin/device-import/commit。接口和客户导入分别签发预览凭证，不可交叉提交。示例行按明确标记跳过，不固定忽略某一行；删除示例后仍能导入第一条真实数据。兼容不含行类型的旧信息表。
