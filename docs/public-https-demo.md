# 临时 HTTPS 客户端演示

运行项目根目录 `public-https-demo.cmd`，使用 Windows 内置 SSH 连接 localhost.run，将本机客户端代理端口 4201 暴露为临时 HTTPS 网址。无需填写 IP 访问码。

电脑、后端 8180、客户端 3101 和隧道窗口均需保持运行；Ctrl+C 结束分享。窗口会在 SSH 断开时清理当前地址配置，重新启动可能换域名。匿名免费通道不能保证长期稳定。

网址、二维码分别写入 `.local-preview/tunnel/public.json` 和 `.local-preview/tunnel/customer-https.png`，企业后台设备码窗口默认使用当前地址。临时地址只能用于演示，正式设备标签使用固定域名。

网关只开放客户端文件及必要业务接口，不开放企业后台 `/admin`、维保云 `/platform` 或平台运营管理接口；网页和 API 使用同一 HTTPS 域名。保持原有登录与业务权限。

工具文档：https://localhost.run/docs/ 。先前的 loca.lt 网址与 IP 访问码不再使用。当前已建立的手动测试隧道与以后通过启动脚本建立的隧道地址可能不同，以运行时输出为准。
