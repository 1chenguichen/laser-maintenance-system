## 1. 概述

### 1.1 产品背景

激光设备（切割机、焊接机、打标机等）价值高、专业性强，维修依赖完善的售后体系。目前行业缺乏统一的数字化管理平台：

- 客户报修流程不规范，维修进度不透明
- 工程师派单依赖人工调度，效率低下
- 提成计算不透明，工程师满意度低
- 配件库存信息不对称，维修周期长

### 1.2 客户痛点

**客户侧痛点：**
- 设备故障后不知道找谁维修，只能通过搜索引擎查询，信息不权威
- 报修后不知道维修进度，工程师什么时候到完全不透明
- 维修费用没有标准，漫天要价也无法对比
- 维修完成后没有记录，下次故障无法追溯历史

**工程师侧痛点：**
- 派单靠人工电话通知，经常跑空趟（客户已经自行解决）
- 提成计算不透明，不知道自己的收益是如何得出的
- 配件库存不清楚，到了现场发现缺少配件白跑一趟
- 月底对账时发现订单和收益对不上，申诉困难

**客服侧痛点：**
- 工单量大时难以跟踪，每个客户都要电话回访确认进度
- 工程师位置不可见，无法判断工程师是否绕路
- 客户投诉时缺乏完整的历史记录，难以判断责任
- 数据统计靠手工 Excel，效率低且容易出错

### 1.3 产品目标

构建连接**客户**、**工程师**、**客服**三方的数字化维保系统，实现报修→派单→维修→结算→评价的全链路数字化管理。

### 1.4 产品愿景

**让每一台激光设备都能获得及时、专业、透明的服务**

我们致力于构建一个连接设备、客户与工程师的数字化维保平台，通过智能化派单、实时进度追踪、透明化收益机制，解决传统维保行业的信息不对称、响应慢、收费乱、追溯难等痛点，最终实现：

- **更快的响应**：从报修到工程师到场 ≤ 30 分钟
- **更透明的服务**：费用有标准、进度可查、历史可追溯
- **更公平的合作**：抢单靠手速、提成靠努力
- **更智能的管理**：数据驱动决策、流程自动化

### 1.5 产品价值

**客户价值：**
- 随时随地快速报修，无需电话等待
- 维修进度实时可查，工程师位置一目了然
- 费用透明有标准，30% 定金保障资金安全
- 维修历史永久存档，下次故障可追溯

**工程师价值：**
- 抢单机制公平透明，多劳多得
- 阶梯提成让收入持续增长（20%→25%→30%）
- GPS 距离排序减少空跑，提高工作效率
- 月度收益自动计算，账目清晰无误

**客服价值：**
- 数字化工单管理，减少电话回访工作量
- 实时监控工程师位置，科学调度派单
- 完整历史记录快速溯源，投诉处理有据可依
- 数据看板自动生成，告别手工 Excel

**企业价值：**
- 派单效率提升 50% 以上
- 工程师月均接单量提升 30%
- 客户满意度提升至 4.5 星以上
- 配件库存周转率提升，减少资金占用

### 1.5 名词术语

| 名词 | 英文 | 说明 |
|------|------|------|
| 工单 | Work Order | 从客户报修到维修完成的完整服务记录 |
| 派单 | Dispatch | 将工单分配给工程师的过程 |
| 抢单 | Grab Order | 工程师从订单池主动接取工单 |
| 指派 | Assign | 客服指定工程师接单 |
| 定金 | Deposit | 维修前预付的费用，通常为总费用的 30% |
| 尾款 | Balance Payment | 维修完工后支付的剩余费用 |
| 提成 | Commission | 工程师完成订单后获得的收益 |
| 配件 | Parts | 维修所使用的零部件 |
| 完工 | Complete | 工程师完成维修工作 |
| 评价 | Review | 客户对维修服务的评分和反馈 |

| 指标 | 目标 |
|------|------|
| 工单响应时间 | 从报修到工程师接单 ≤ 30 分钟 |
| 工程师月均接单量 | 提升 30% |
| 客户满意度 | ≥ 4.5 星 |
| 配件缺货导致的改约率 | < 5% |

| 角色 | 描述 |

| 工程师 | 维修服务提供方，通过接单赚取提成 |

### 2.2 各端需求池

**客户 App 需求池：**
- 设备扫码绑定 / 序列号查询
- 快速故障报修（故障类型 + 描述 + 照片）
- 30% 定金预支付
- 报修进度实时追踪
- 维修方案确认 / 尾款支付
- 完工评价（1-5 星 + 文字）
- AI 智能客服（自动诊断 + 转人工）
- 退款申请

**工程师 App 需求池：**
- 状态切换（在线 / 离线 / 工作中）
- GPS 实时定位上报
- 订单池抢单（按距离排序）
- 客服指派单接收
- 到达打卡 / 完工提交
- 维修报价 / 收款确认
- 客户电子签名
- 配件库存查询
- AI 故障诊断助手
- 月度收益统计

**客服后台需求池：**
- 工单管理（筛选 / 分类 / 详情）
- 远程诊断（在线沟通）
- 客服工作台（待接入队列 / 实时会话）
- 改派工单
- 客户 / 工程师 / 设备管理
- 配件库存管理
- 数据统计（工单量 / 响应时长 / 收入）

**派单引擎需求池：**
- 抢单池（订单进入 → 工程师可见）
- 距离排序（GPS 实时计算）
- 抢单锁定（防并发）
- 指定派单（客服选择工程师）
- 派单通知推送

**提成系统需求池：**
- 月度阶梯计算（1-10 单 20% / 11-30 单 25% / 31+ 单 30%）
- 月度结算单生成
- 收益明细查询

**支付系统需求池：**
- 微信 / 支付宝定金预付
- 尾款支付
- 退款处理（全额 / 部分）

| 工程师统计 | 工程师接单量、好评率、收益 | P1 |
| 收入统计 | 平台收入、退款统计 | P2 |

---

### 3.4 派单引擎

#### 3.4.1 抢单模式

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 订单池 | 新工单进入可抢单池 | P0 |
| 距离排序 | 按工程师与客户距离排序 | P0 |
| 抢单锁定 | 同一工单同一时刻只能被一个工程师抢到 | P0 |

#### 3.4.2 指定派单模式

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 客服指派 | 客服选择指定工程师派单 | P0 |
| 系统推送 | 向指定工程师发送派单通知 | P0 |

### 3.5 提成系统

#### 3.5.1 提成规则

| 月订单量 | 提成比例 |
|---------|---------|
| 1-10 单 | 20% |
| 11-30 单 | 25% |
| 31+ 单 | 30% |

**规则说明**：
- 按自然月统计，每月 1 日重置
- 以工单完工时间计算
- 提成 = 工单总价 × 提成比例

#### 3.5.2 结算

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 月度结算 | 每月 1 日生成上月结算单 | P0 |
| 收益明细 | 显示每单收益计算明细 | P0 |

---

### 3.6 支付系统

#### 3.6.1 定金预付

- 金额：维修总费用的 30%
- 时机：工程师报价客户确认后
- 方式：微信支付 / 支付宝

#### 3.6.2 尾款支付

- 金额：维修总费用的 70%
- 时机：维修完工客户确认后
- 方式：微信支付 / 支付宝

#### 3.6.3 退款规则

| 场景 | 退款规则 |
|------|---------|
| 客户取消（工程师未到） | 全额退款 |
| 客户取消（工程师已到） | 扣除上门费，退还剩余 |
| 客户投诉退款 | 客服审核后处理 |

| 术语 | 定义 |
|------|------|
