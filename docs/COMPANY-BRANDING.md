# 企业资料与品牌标识

企业管理后台新增「企业资料」（/company）。企业管理员可以维护企业名称、简称、英文名称、行业、简介、联系人、联系电话、邮箱、官网、地址、服务区域和服务时间。

展示位置：
- 左上角固定品牌区：企业Logo、简称、设备服务管理副标题。
- 顶栏：当前企业全称与独立的账号退出操作。
- 仪表盘：企业概览，包括Logo、全称、简介、行业、服务区域和联系信息。
- 客服工作台：紧凑企业标识，可直接进入企业资料。
- 浏览器标签：企业名称和Logo图标。
- 维保云：企业列表与开通详情显示同一份Logo、名称和联系人。返回平台窗口时刷新列表。

维护规则：
- 基本资料点击「保存企业资料」后生效；Logo上传、更换和移除单独保存。修改基本资料时先保存或放弃，再调整Logo。
- Logo支持PNG、JPEG、WebP，最大2MB。后台检查文件实际内容，限制像素数，去除元数据并统一转为最大512像素PNG。
- 未设置Logo时显示企业名称首字。仅带当前企业身份的管理账号可修改。
- 套餐、员工额度、附件额度、服务有效期只读，由平台调整。前端新增字段不会授予平台权限。
- 保存企业全称会同步更新平台企业记录及下一次登录返回的企业名称，不改变企业ID、账号或业务数据归属。
- 同源后台窗口通过变更事件同步，切回窗口和每分钟也会从服务端检查最新资料。冲突时返回409，保留当前输入并提示重新加载。
- 资料更新、Logo更换和移除记录于平台操作日志；日志记录是否有Logo，不复制图片正文。
- 未保存资料离开页面会提示。演示资料有明确提示，管理员保存正式资料后去除该提示。

实现：platform.tenants 新增 company_profile JSONB、company_logo TEXT、company_version INTEGER。Logo存为经过处理的数据URL，无公开上传目录或跨企业图片URL。升级时由平台schema初始化执行可重复的 ADD COLUMN IF NOT EXISTS。

演示：assets/company-demo 中保留四组原创SVG与PNG图形，包括华东激光、绍辉自动化及两家演示企业。这些是演示标志，不是企业正式商标；简介、地址、邮箱等也为示例。初始化保留既有企业名称和联系人，并在.local-preview保存初始化前快照。
