# 全国激光设备售后服务市场（首版）

## 设备报修与统一订单（后续更新，以本节为准）

客户端订单页现已合并展示平台服务单和企业售后工单，支持状态、来源和设备/SN/单号搜索；`orders.html` 与 `market-orders.html` 均使用同一列表。历史企业工单保留原数据库、单号、报价、付款、合同和详情流程，不复制成新的平台单。

从设备卡报修会直接带入设备，不再展示全量设备卡要求重复选择；仍可主动点击“更换设备”。通用入口才需要选择设备。新表单的普通报修通过 `/market/device-repairs` 进入平台待派单；若显式选择有效企业服务合同，则沿用企业协议报修，原人工费/配件折扣权益继续生效。设备在保信息会作为报修快照保存，但不自动认定任何一方付款责任。

平台报修由服务端核验客户设备与地址归属，保存全局设备引用、权威型号、SN、原关联企业及需求资料。平台运营和所属企业的“平台服务协作”中可查看 SN；实际履约工程师在接单后的详情中可查看设备信息。请求重复提交使用客户级提交编号和指纹拦截，不重复创建企业工单或平台单。

故障照片通过认证上传，转换为 WebP 后存放在后端非公开目录 `private-market-media`，图片元数据位于 `market.attachments`。只允许报修客户、有关企业、平台及获派工程师读取关联照片；未接单工程师及无关企业不可读取。单次最多 5 张，每张输入上限 5 MB，客户每日上传限额 40 张；正式运营仍需配置备份与附件生命周期管理。

自动设备报修使用内部服务类型，不作为可售服务项目出现在找服务目录，不影响人工发布的市场服务。

## 四端分工与入口

- 客户端 `http://localhost:3101/services.html`：按城市、设备服务类别找服务，选择已绑定设备或手填型号，提交需求。底部为首页、找服务、设备、订单、我的，保留蓝色设计。
- 工程师端 `http://localhost:3102/workbench.html`：绿色工作台，平台任务、接单大厅、培训与资质、服务身份。企业任务与移动仓继续独立处理。
- 企业后台 `http://localhost:3100/service-network`：新增“平台服务协作”，查看本企业关联的市场服务单及履约信息。原工单管理继续保留。
- 维保云 `http://localhost:3103/platform-market.html`：从“服务市场与培训”进入，发布/下架服务、登记培训地点和课程、审核工程师、登记考核、指派服务单。

以上入口沿用各自已有登录，不新增企业代码输入。

## 工单流程

提交需求 → 合格工程师领取/平台指派 → 工程师确认 → 提交报价 → 客户确认报价 → 开始服务 → 提交完工记录 → 客户验收。

未开始服务的早期阶段可说明原因后取消；报价已确认及服务进行中的纠纷需联系平台，首版尚无仲裁流程。每次操作记录事件，更新版本号；旧页面重复操作会提示刷新。并发领取同一任务只允许一人成功。

## 身份、资格和企业数据

个人账号不固定归属某一家企业。客户的设备可分别关联不同服务企业；新市场需求单独记录设备原关联企业、发布服务的承接企业、实际履约企业、工程师和客户。

企业内部业务仍使用独立企业数据库。市场协作记录存放在控制库 `market` schema，由服务端根据角色和工单关系授权：客户只看自己的服务单；工程师只看已分配给自己的详情；接单大厅不提供客户电话、地址和故障详情；相关企业只看自己参与的服务单，不获得其他企业内部业务库权限。平台运营可查看市场协作记录。

设备原关联企业不自动承担市场服务费用。保障内原厂/企业报修仍在设备原路径进行，不能将市场报价确认误认为扣款或原企业付款授权。

企业员工需要已有企业员工关系；个人也可以在客户端“我的 → 申请成为服务工程师”提交平台合作身份申请。平台审核通过后，可用同一手机号登录工程师端。实际接单还要求：审核通过、服务城市匹配、对应服务类别资质未过期；企业指定服务只向该企业有效员工开放。机构工程师领取开放平台任务时须选择实际履约企业。

培训报名只是登记。平台核实完成培训并记录考核通过后，才授予该类别一年有效期的接单资质。首版为人工审核与人工考核记录，不提供自动认证。修改接单资料后重新进入待审核。

## 演示数据与测试

已添加四个标明“演示”的服务项目和三个演示培训地点/课程，不生成真实订单、资格或付款。培训地址为虚构演示信息。

`node backend/test/service-market.mjs` 使用临时个人账号、服务与课程测试审核、报名、考核、失效资质、城市、指定企业权限、客户隐私、并发抢单、版本冲突、完整服务流转和真实浏览器页面。测试完成自动删除本次测试业务数据。需要后端 8180、四端预览服务和通过 `browser-check.cmd` 打开的 Edge 测试连接 9324。

## 首版范围

这是平台市场与多租户 SaaS 并行的可运行首版，支持手动派单和按资格领取。尚未实现地图距离匹配、自动调度、支付托管、平台抽佣、跨企业结算、退款仲裁、真实短信、微信身份认证、原生小程序/App 和正式培训认证。这些能力不能由当前演示流程代替。
